# CSAN0003 — Null value introduction

Status: Admitted
Category: Nullability
Certainty: deterministic candidate
Disposition: block only after admission and only within qualified scope

## Mechanism

Explicit null literals and reference-typed default operations are inspected semantically.

## False-positive boundary

A null constant pattern used to recognize boundary input is allowed; implicit optional arguments are not source introductions.

match a reviewed policy grant with a finding fingerprint, owner, reason, and
expiry; otherwise CSAP0001 remains evidence.
