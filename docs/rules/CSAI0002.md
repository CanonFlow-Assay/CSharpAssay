# CSAI0002 — Mutable collection exposure

Status: Prototype
Category: Immutability
Certainty: deterministic candidate
Disposition: block only after admission and only within qualified scope

## Mechanism

Public record property metadata identity is matched against a bounded mutable collection set.

## False-positive boundary

Custom collections are not classified without an admitted metadata adapter.

## Evidence

- Compliant specimen: `specimens/Compat.Good/CSAI0002/`
- Violation specimen: `specimens/Compat.Bad/CSAI0002/`
- Suppression specimen: `specimens/Compat.Bad/CSAI0002/Suppression.cs`
- Fault specimen: `specimens/Faults/CSAI0002/Malformed.cs`

## Suppression

A compiler pragma or `SuppressMessage` is not authorization. Suppression must
match a reviewed policy grant with a finding fingerprint, owner, reason, and
expiry; otherwise CSAP0001 remains evidence.

## Fix safety

No automatic fix. Select an immutable representation and review allocation and serialization behavior.
