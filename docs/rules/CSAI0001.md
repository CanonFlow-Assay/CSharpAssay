# CSAI0001 — Mutable setter on immutable carrier

Status: Admitted
Category: Immutability
Certainty: deterministic candidate
Disposition: block only after admission and only within qualified scope

## Mechanism

Public record properties are inspected for public non-init set accessors.

## False-positive boundary

Ordinary mutable classes are not assumed to be immutable carriers by this restricted rule.

## Evidence

- Compliant specimen: `specimens/Compat.Good/CSAI0001/`
- Violation specimen: `specimens/Compat.Bad/CSAI0001/`
- Suppression specimen: `specimens/Compat.Bad/CSAI0001/Suppression.cs`
- Fault specimen: `specimens/Faults/CSAI0001/Malformed.cs`

## Suppression

A compiler pragma or `SuppressMessage` is not authorization. Suppression must
match a reviewed policy grant with a finding fingerprint, owner, reason, and
expiry; otherwise CSAP0001 remains evidence.

## Fix safety

A conservative auto-property set-to-init fix is available; behavior-sensitive properties require review.
