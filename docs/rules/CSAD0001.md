# CSAD0001 — Configured primitive obsession

Status: Prototype advisory
Category: Domain modeling
Certainty: contextual
Disposition: advise; never a release blocker

## Mechanism

A public method parameter is reported only when its name exactly matches a
`domainPrimitives` glossary entry and its type is a raw C# primitive or
`System.Guid`. The finding names the configured domain type.

Without a glossary entry, this rule emits nothing. Naming similarity alone is
not evidence that two values share domain semantics.

## Review

Confirm that the configured type has validated construction and that applying
it improves rather than obscures the API. Framework bindings and wire contracts
may justify keeping the primitive in a shell adapter.

No automatic fix is offered.
