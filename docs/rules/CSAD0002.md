# CSAD0002 — State flags

Status: Prototype advisory
Category: Domain modeling
Certainty: heuristic
Disposition: advise; never a release blocker

## Mechanism

A source type with at least two visible instance boolean fields or properties
is suggested for review as a possible hidden state machine.

Independent capabilities, feature switches, framework bindings, and query
projections are common valid counterexamples. Consider a closed state model
only when combinations are mutually exclusive or illegal.

No automatic fix is offered.
