# CSAE0002 — Expected failure at a public boundary

Status: Prototype advisory
Category: Effects
Certainty: contextual
Disposition: advise; never a release blocker

## Mechanism

An explicit throw of `ArgumentException`, `InvalidOperationException`,
`FormatException`, `KeyNotFoundException`, or a derived type from an owned
public method is reported for review.

The tool cannot infer whether the failure is expected domain data or a genuine
exceptional/programmer error. In a configured functional core, consider a
declared result or closed outcome for expected failures. Framework and shell
contracts may correctly require exceptions.

No automatic fix is offered.
