# CSAI0003 — Mutable shell leakage

Status: Prototype advisory
Category: Immutability
Certainty: contextual
Disposition: advise; never a release blocker

## Mechanism

An owned public ordinary-class property or ordinary method return type that
exposes an array or known mutable collection is reported. Record carriers are
covered separately by the admitted `CSAI0002` rule.

Review ownership: returning a defensive copy, immutable collection, or
read-only projection can prevent shell mutation from crossing into the core.
Framework models and intentionally mutable owned buffers are valid contextual
exceptions.

No automatic fix is offered.
