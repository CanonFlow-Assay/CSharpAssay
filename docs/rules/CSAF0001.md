# CSAF0001 — Behavior-only type candidate

Status: Prototype advisory
Category: Functions
Certainty: heuristic
Disposition: advise; never a release blocker

## Mechanism

The restricted detector observes single-method `*Strategy` interfaces,
multi-method `*Visitor` interfaces, and conventional `*Builder` classes whose
ordinary methods are limited to `Build`, `With*`, `Add*`, or `Set*`.

Review whether a delegate, pattern match, initializer, or `with` expression
would make the dependency smaller. Keep the type when identity, dependency
injection, framework integration, discoverability, or versioning benefits are
material.

No automatic fix is offered.
