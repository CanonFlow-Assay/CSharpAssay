# CSAN0001 — Nullable analysis disabled

Status: Admitted
Category: Nullability
Certainty: deterministic candidate
Disposition: block only after admission and only within qualified scope

## Mechanism

Nullable directive syntax plus workspace compilation options provide the evidence.

## False-positive boundary

Enabling annotations only is not equivalent to enabling the full nullable context.

- Compliant specimen: `specimens/Compat.Good/CSAN0001/`
- Violation specimen: `specimens/Compat.Bad/CSAN0001/`
- Suppression specimen: `specimens/Compat.Bad/CSAN0001/Suppression.cs`
- Fault specimen: `specimens/Faults/CSAN0001/Malformed.cs`

## Suppression

A compiler pragma or `SuppressMessage` is not authorization. Suppression must
match a reviewed policy grant with a finding fingerprint, owner, reason, and
expiry; otherwise CSAP0001 remains evidence.

## Fix safety

No blind fix. Enable nullable analysis at project scope and adjudicate resulting compiler warnings.
