# CSAF0002 — Loop-to-pipeline opportunity

Status: Prototype advisory
Category: Functions
Certainty: heuristic
Disposition: advise; never a release blocker

## Mechanism

The rule reports only a `foreach` whose body is one `Add` call, optionally
guarded by one `if`. This is a syntactic prompt to compare a `Select`, `Where`,
or combined pipeline.

LINQ is not automatically clearer or faster. Retain the loop when allocation,
ordering, debugging, early exit, mutation ownership, or measured performance
supports it.

No automatic fix is offered.
